# Functional Requirements

## Project Name
FitBuddy AI

## Requirements

1. The system shall allow users to enter their basic information.
2. The system shall validate the entered information.
3. The system shall store user information in the database.
4. The system shall generate a 7-day wellness and fitness plan using Gemini AI.
5. The system shall generate a short nutrition and recovery tip.
6. The system shall display the generated plan to the user.
7. The system shall allow users to submit feedback.
8. The system shall generate an updated plan based on feedback.
9. The system shall store generated plans in the database.
10. The system shall provide an admin view for registered users.
