# UI Design

## Project Name
FitBuddy AI

## Interface Design

FitBuddy AI uses a simple, modern and responsive web interface.

## Main Pages

### Home Page

The home page contains:

- FitBuddy AI title
- Project description
- User input form
- Name field
- User ID field
- Age field
- Weight field
- Fitness goal field
- Workout intensity selection
- Generate Fitness Plan button

### Result Page

The result page displays:

- User information
- Wellness tip
- 7-day fitness plan
- Feedback form
- Updated plan

### Error Page

The error page displays:

- Error message
- Friendly explanation
- Try Again button

### Admin Page

The admin page displays registered users and their basic information.

## Design Features

- Responsive layout
- Simple navigation
- Modern card-based interface
- Clear buttons and forms
- Dark themed visual design
