# FitBuddy AI – Project Summary

## Project Name

FitBuddy AI

## Project Type

AI-Powered Web Application

## Purpose

To generate a simple personalized 7-day wellness and fitness plan using Artificial Intelligence.

## Key Technologies

Python, FastAPI, Google Gemini AI, SQLite, SQLAlchemy, Jinja2, HTML and CSS.

## Main Features

- User input
- AI-generated 7-day plan
- Wellness tip
- Feedback-based plan update
- Database storage
- Responsive interface
- Admin user view

## Benefits

- Simple user interface
- Personalized planning
- AI-powered assistance
- Feedback-based updates
- Easy web-based access

## Future Scope

- Progress tracking
- Reminders
- Exercise demonstrations
- Calendar integration
- User authentication

## Conclusion

FitBuddy AI demonstrates the practical integration of Generative AI with a modern web application.
