# FitBuddy AI – User Guide

## 1. Open the Application

Start the FastAPI server and open the application in a web browser.

## 2. Enter User Information

Enter:

- Name
- User ID
- Age
- Weight
- Fitness Goal
- Workout Intensity

## 3. Generate Plan

Click:

Generate My Fitness Plan

The application sends the information to the backend and Gemini AI generates a 7-day wellness and fitness plan.

## 4. View the Result

The result page displays:

- User information
- Wellness tip
- 7-day plan

## 5. Submit Feedback

Enter feedback about the generated plan and submit it.

## 6. View Updated Plan

FitBuddy AI uses the feedback to generate an updated 7-day plan.

## 7. Error Handling

If an error occurs, the application displays a friendly error message and provides an option to try again.

## Safety

The application is designed to provide general wellness guidance and does not replace professional medical advice.
