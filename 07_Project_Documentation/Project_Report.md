# FitBuddy AI – Project Report

## 1. Introduction

FitBuddy AI is an AI-powered web application that generates a simple personalized 7-day wellness and fitness plan.

The application uses Google Gemini AI, FastAPI, SQLite and Jinja2 to provide an interactive web-based experience.

## 2. Problem Statement

Students and beginners may find it difficult to organize a simple weekly wellness and fitness routine.

FitBuddy AI provides an easy way to generate a structured 7-day plan based on user-provided information.

## 3. Objectives

- Develop an AI-powered wellness planning application.
- Generate a 7-day plan using Gemini AI.
- Provide a simple nutrition and recovery tip.
- Allow users to provide feedback.
- Generate an updated plan based on feedback.
- Store user and plan information using SQLite.
