# FitBuddy AI – Demo Script

## 1. Introduction

Hello everyone.

Our project is called FitBuddy AI.

FitBuddy AI is an AI-powered web application that generates a simple personalized 7-day wellness and fitness plan.

## 2. Purpose

The main purpose of FitBuddy AI is to help users create a simple weekly wellness and fitness routine using Artificial Intelligence.

## 3. Technologies Used

Our project uses:

- Python
- FastAPI
- Google Gemini AI
- SQLite
- SQLAlchemy
- Jinja2
- HTML
- CSS

## 4. Project Execution

First, we open the FitBuddy AI web application.

Next, we enter the required user information such as name, user ID, age, weight, goal and workout intensity.

After submitting the form, FastAPI receives and validates the information.

The application then uses Gemini AI to generate a 7-day wellness and fitness plan.

The generated plan and wellness tip are displayed on the result page.

The information is also stored in the SQLite database.

## 5. Feedback Feature

The user can provide feedback about the generated plan.

The feedback is sent to Gemini AI, which generates an updated plan.

## 6. Final Output

The final output is a simple personalized 7-day wellness and fitness plan with a wellness tip and feedback-based update.

## 7. Conclusion

FitBuddy AI demonstrates how Generative AI can be integrated with a web application to provide personalized wellness planning.
