# FitBuddy AI – Demo Script

## 1. Introduction

Hello everyone.

Our project is called FitBuddy AI.

FitBuddy AI is an AI-powered web application that generates a simple personalized 7-day wellness and fitness plan.

## 2. Purpose

The main purpose of FitBuddy AI is to help users create a simple weekly wellness and fitness routine using Artificial Intelligence.

## 3. Technologies Used

Our project uses:

* Python
* FastAPI
* Google Gemini AI
* SQLite
* SQLAlchemy
* Jinja2
* HTML
* CSS

## 4. Project Execution

First, we open the FitBuddy AI web application.

Next, we enter the required user information such as name, user ID, age, goal and workout intensity.

After submitting the form, FastAPI receives and validates the information.

The application then uses Gemini AI to generate a 7-day wellness and fitness plan.

The generated plan and wellness tip are displayed on the result page.

The user and plan information is stored in the SQLite database.

## 5. Feedback Feature

The user can provide feedback about the generated plan.

The feedback is processed by the application and sent to Gemini AI to generate a revised plan.

The updated plan is then displayed on the result page.

## 6. Admin Dashboard

FitBuddy AI also includes an admin dashboard.

The administrator can securely log in and view registered users and their plan status.

## 7. API Documentation

The application provides API endpoints using FastAPI.

Swagger documentation is available for testing and viewing the available API operations.

## 8. Final Output

The final output is a personalized 7-day wellness and fitness plan with:

* Wellness tip
* Feedback-based plan update
* Database storage
* Admin dashboard
* API documentation

## 9. Conclusion

FitBuddy AI demonstrates how Generative AI can be integrated with a web application to provide a personalized wellness planning experience.

Thank you.
